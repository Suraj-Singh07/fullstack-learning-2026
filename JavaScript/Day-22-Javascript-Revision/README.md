## 🧩 Practice Programs

### 1. Age Category

Created a function that categorizes a person based on age:

- Under 18 → Minor
- 18–59 → Adult
- 60 or above → Senior

### 2. Password Length Checker

Created a function to check whether a password contains fewer than 6 characters.

- Fewer than 6 characters → Too short
- 6 or more characters → OK

### 3. BMI Category

Created a function that calculates BMI and returns a category:

- Underweight
- Normal
- Overweight
- Obese

### 4. Array Sum

Created a function that takes an array of numbers and calculates the total sum using a `for` loop.

### 5. Highest Scorer

Created a function that takes an array of student objects and finds the student with the highest score.
