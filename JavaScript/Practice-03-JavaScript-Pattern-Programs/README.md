# Practice 03 - JavaScript Pattern Programs

This folder contains my JavaScript pattern programming practice from my **FullStack Learning 2026** journey.

## Topics Practiced

* Nested `for` loops
* Pattern printing
* String concatenation
* Using `Math.abs()`
* Conditional (`? :`) operator
* Building rows before printing

## Pattern Programs Created

### 1. Left Half Pyramid

Prints a growing triangle of `*`.

Example:

```text
*
**
***
****
```

### 2. Right-Aligned Star Pyramid

Prints a right-aligned star pattern.

### 3. Right-Aligned Number Pyramid

Prints numbers in increasing order for each row.

Example:

```text
   1
  12
 123
1234
```

### 4. Diamond Number Pattern

Prints a symmetric number pattern using the same number in each row.

### 5. Butterfly Pattern

Prints a butterfly-shaped pattern using `*` and spaces.
