# Practice-01 - JavaScript Prime and Even/Odd Programs

This folder contains my Day 19 JavaScript practice from my **FullStack Learning 2026** journey.

## Topics Practiced

* Nested `for` loops
* Number validation using `if-else`
* Even and odd number checking
* Prime number logic
* Using `prompt()` for user input
* Building comma-separated output strings

## Programs Created

### 1. Even and Odd Numbers up to N

* Takes a number from the user.
* Prints all even and odd numbers from **1** to the entered number.

### 2. Prime Number Checker

* Takes a number as input.
* Checks whether it is prime or not using a `for` loop.

### 3. Prime and Non-Prime Numbers up to N

* Takes a number from the user.
* Prints all prime numbers up to that number.
* Prints all non-prime numbers up to that number.

## Technologies Used

* HTML5
