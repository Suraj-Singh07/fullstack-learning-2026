# JavaScript Conditionals and Logical Operators Practice

JavaScript practice programs covering `else-if` ladders, logical operators, `prompt()`, `alert()`, and basic user input.

## Topics Learned

- if-else
- else-if ladder
- Logical AND (`&&`)
- Logical OR (`||`)
- Logical NOT (`!`)
- `prompt()`
- `alert()`
- `Number()`
- User input and conditional logic

## Programs

### Grade System
A program that calculates a percentage and assigns a grade using an else-if ladder.

### Rock Paper Scissors
A simple Rock Paper Scissors program using user input, logical operators, and conditional statements.

### Number Input
A simple program that takes a number using `prompt()`, converts it using `Number()`, and performs an operation.
