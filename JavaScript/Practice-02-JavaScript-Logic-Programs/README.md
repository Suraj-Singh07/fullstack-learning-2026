# Practice 02 - JavaScript Logic Programs

This folder contains my JavaScript logic practice from my **FullStack Learning 2026** journey.

## Topics Practiced

* `for` loops
* Arrays
* Strings
* Reversing values
* Palindrome checking
* Factorial calculation

## Programs Created

### 1. Reverse an Array

* Prints the elements of an array in reverse order using a `for` loop.

### 2. Palindrome Checker

* Takes user input using `prompt()`.
* Reverses the input.
* Checks whether it is a palindrome.

### 3. Factorial Calculator

* Takes a number as input.
* Calculates its factorial using a `for` loop.
* Handles invalid input for negative numbers.
