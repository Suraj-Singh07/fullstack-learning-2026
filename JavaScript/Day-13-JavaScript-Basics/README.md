# Assignment - JavaScript Basics

## Objective

Learn the fundamentals of JavaScript by linking an external JavaScript file with an HTML document and understanding basic data types and console output.

## Topics Practiced

- Linking an external JavaScript file using the `<script>` tag
- Using `console.log()` to print output to the browser console
- JavaScript primitive data types:
  - Number
  - String
  - Boolean
  - Null
  - Undefined
- Using the `typeof` operator to check the data type of a value

## Files

- `index.html`
- `index.js`

## Concepts Covered

- External JavaScript
- Console output
- Primitive data types
- Type checking with `typeof`

## Output

The JavaScript file prints different values to the browser console and displays their data types using the `typeof` operator.
