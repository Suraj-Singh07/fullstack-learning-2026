# Day 12 - Pseudo Elements, CSS Variables, Transform & Transition

## Objective

Learn how to style elements using pseudo elements, create reusable CSS variables, and apply transformations and transitions for interactive UI effects.

## Topics Practiced

- CSS Variables
- :root
- Pseudo Elements
  - ::before
  - ::after
  - ::first-letter
- CSS Selectors
  - :first-child
  - :nth-child()
- CSS Transform
  - translate()
  - scale()
  - rotate()
  - skew()
- CSS Transition
- DOM Tree (Theory)

## Files

- index.html
- style.css

## Learning Outcome

- Learned how to insert content using pseudo elements.
- Used CSS variables for reusable values.
- Practiced selecting elements with pseudo classes.
- Applied transform functions to move and resize elements.
- Created smooth animations using CSS transitions.
- Understood the basics of the HTML DOM Tree.
